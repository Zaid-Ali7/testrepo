This is a paragraph of text. It demonstrates the basic structure of an HTML document.

We used the following essential elements:

  • **<!DOCTYPE html>**: Declares the document type.
  • **<html>**: The root element of the page.
  • **<head>**: Contains metadata about the page (not visible).
  • **<title>**: Sets the text that appears in the browser tab.
  • **<body>**: Contains all the visible content.
  • **<h1>**: A main heading.
  • **<p>**: A standard paragraph.
  • **<ul>** and **<li>**: An unordered list.
